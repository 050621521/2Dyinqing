# 运行时切换动画素材 + 角色按选择切换动画 设计

> 日期：2026-06-24
> 范围：引擎新增「设置动画素材」蓝图节点（通用能力）+ MyGame `角色.bp` 按全局变量「角色」切换武夫/机械师动画。

## 背景与问题

单人 PVE 流程里，「角色选择界面」让玩家选「武夫 / 机械师」，写入全局变量 `角色`（枚举：0=武夫，1=机械师）。但进入地图后角色始终显示武夫动画，没有按选择切换。

根因有两处：

1. **引擎缺口**：角色身上的「动画器」组件只在出生时按 `animAsset`（一套精灵表路径）初始化一次。现有动画节点「播放动画」(`Self.Anim.Play`) 只能切换**片段**（walk_up/walk_down…），无法在运行时切换**整套动画素材**。因此没有任何手段在游戏里换角色形象。
2. **内容写死**：`MyGame/Blueprints/角色.bp` 的 `defaults.animAsset` 写死为 `动画/武夫.anim`，且没有读取全局变量 `角色` 做切换。

## 目标

- 玩家在选择界面选谁，进入地图就显示对应角色（武夫或机械师）的 8 方向行走动画。
- 引擎新增的能力做成**通用节点**，不写死本游戏专用，便于后续任何「换装 / 换形象」复用。

## 方案

### 第一步 · 引擎：新增蓝图节点「设置动画素材」(`Self.Anim.SetAsset`)

**节点定义**（`BlueprintEditor.cpp` 的 `nodeDefs()`，置于「Self 动画器」分类，紧邻 `Self.Anim.Play` / `Self.Anim.Stop`）：

- typeId：`Self.Anim.SetAsset`
- 显示名：**设置动画素材**
- header 颜色：沿用动画器分类色 `#2a4040`
- 引脚：
  - `exec_in`（exec，入）
  - `exec_out`（exec，出）
  - `asset`（显示名「素材」，数据入，新引脚类型 `ValueKind::AnimAssetRef`）

**新引脚类型 `AnimAssetRef`**（`BlueprintEditor.h` 的 `ValueKind` 枚举）：

- 含义：下拉选择项目 `动画/` 目录下的 `.anim` 文件，写回**绝对路径**（与 `defaults.animAsset` 存储格式一致）。
- 下拉填充：新增 `buildAnimAssetItems()`，扫描 `{project}/动画/*.anim`，返回 `(显示名=文件名去后缀, 值=绝对路径)` 列表；在内联编辑的 `mousePress` 分发里新增 `case ValueKind::AnimAssetRef`，调用 `showListPicker(... "选择动画素材" ...)`，无资源时退回打字（与 `AnimClipRef` 同模式）。
- 若有「该引脚类型不可被连线/可被连线」等既有判定列表（如 `BlueprintEditor.cpp:1563` 对 `AnimClipRef` 的归类），`AnimAssetRef` 按与 `AnimClipRef` 相同的取向处理。

**运行时执行**（`ActorBPRuntime.cpp`，紧邻 `Self.Anim.Play` 分支）：

```
if (node->type == "Self.Anim.SetAsset") {
    const QString path = resolveDataPin(nodeId, "asset").toString();
    if (!path.isEmpty() && self->animAsset != path) {
        self->animAsset = path;
        // 当前片段无缝接上：保留 animCurClip 与 animPlaying，
        // 仅按新素材重算当前帧的源矩形（帧序号被新片段帧数夹取）。
        // 由 BPRuntime 暴露一个按新素材重解析当前帧的入口完成。
    }
    return "exec_out";
}
```

**无缝接上的实现**：`BPRuntime` 的 `applyAnimFrame()` 是静态函数，`animAssetFor()` 已有素材缓存。新增一个公开方法（例如 `BPRuntime::reapplyAnimFrame(ActorData&)`），按 `a.animAsset` 取缓存素材、用 `a.animCurClip` 找片段、调用 `applyAnimFrame` 重算 `animSrc/animSheetPath`，并把 `animFrameIndex` 夹到新片段帧数内。`ActorBPRuntime` 通过其持有的 `BPRuntime` 指针调用它。这样切换素材后，角色停在同一动作、同一相对帧，不闪回第一帧。

> 设计取舍：`机械师.anim` 与 `武夫.anim` 同为 6 列 8 行、单帧 64×64、片段名一致（walk_up/down/left/right），因此切换后片段名与帧序号天然对齐，无需额外映射。

### 第二步 · 内容：`MyGame/Blueprints/角色.bp` 按全局变量切换

在「开始运行」(`Event.BeginPlay`) 时决定素材：

```
开始运行(Event.BeginPlay)
  → 条件分支(Flow.Branch)
       条件 = [获取全局变量「角色」(Global.Get) == 机械师(枚举值 1)]   // 用 Cmp.EQ
       True  → 设置动画素材(Self.Anim.SetAsset, asset = .../动画/机械师.anim)
       False → 设置动画素材(Self.Anim.SetAsset, asset = .../动画/武夫.anim)
```

- `defaults.animAsset` 保留为 `动画/武夫.anim`，作为**编辑器静态预览**用（运行时被上面逻辑覆盖）。
- 枚举比较：全局变量 `角色` 为 `枚举:角色`，比较值用枚举值 `1`（机械师），走既有 `BPValue.typedEquals` 路径。

## 数据流

```
角色选择界面：玩家点选 → 写全局变量 角色 (0/1)
        │ 跨关卡保留（m_globalVars）
        ▼
标准地图界面运行：角色 ActorBPRuntime.triggerBeginPlay()
        → 读 角色 → Self.Anim.SetAsset 设 self.animAsset
        → BPRuntime.reapplyAnimFrame 重算当前帧
        ▼
GameViewport 用 animSheetPath/animSrc 绘制对应角色
```

## 不做（YAGNI）

- 不为「换装」做通用配置表/映射系统，仅处理当前两个角色。
- 不改动画资产格式、不新增片段。
- 不做编辑器内运行时素材的实时预览（仅运行时生效即可）。

## 测试 / 验收

1. 选择界面选「机械师」→ 进标准地图界面运行 → 角色显示机械师精灵表，四向行走动作正确。
2. 选「武夫」→ 显示武夫，行为不变（回归）。
3. 移动中途若触发素材切换（理论路径），动作不闪回第一帧（无缝）。
4. 新节点「设置动画素材」在蓝图右键菜单「Self 动画器」分类下可见，素材引脚为下拉、列出 `动画/` 下的 .anim 文件。
5. 编辑器里打开 `角色.bp`，静态预览仍显示武夫（默认值未破坏）。
