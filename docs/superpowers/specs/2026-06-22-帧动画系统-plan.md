# 帧动画系统 · 实现计划

配套设计：`2026-06-22-帧动画系统-design.md`。原则：每阶段结束都能编译 + 有独立可验证点，可单独提交。

## 阶段 1 — 资源层 `.anim` + 内容浏览器导入

**目标**：能把武夫精灵表 + 元数据 JSON 导入成一个 `.anim` 资源。

- 新增 `launcher/src/models/AnimationAsset.h/.cpp`：
  - `struct AnimClip { QString name, label; int row, startCol=0, frameCount; double fps; bool loop; }`
  - `struct AnimationAsset { QString sheet; int frameW, frameH, cols, rows; QList<AnimClip> clips; }`
  - `bool load(path)` / `bool save(path)`（QJsonDocument）
  - `const AnimClip* findClip(name) const`
  - `QRect frameRect(const AnimClip&, int frameIndex) const`
- `launcher/CMakeLists.txt`：加入新文件，重新 configure。
- `ContentBrowser`：新增「导入动画」按钮；选精灵表 png → 同目录找元数据 JSON（有则解析每行方向生成 clip；无则弹对话框填 `frameW/frameH/cols/rows`，默认每行一 clip / 整行帧数 / 12FPS / 循环）→ 写出 `<名称>.anim`。
- `ContentBrowser`：新增 `type=="anim"` 资源类型（图标 / 标签 / 重命名后缀 / `m_currentTypes`）。

**验证**：导入武夫精灵表 → 生成含 8 个方向 clip 的 `武夫.anim`，资源网格里能看到。

## 阶段 2 — 数据模型字段 + 细节面板「动画器」组件

**目标**：能给精灵对象挂「动画器」组件并配置资源 / 默认片段 / 自动播放，且随关卡持久化。

- `LevelDocument.h`：`ActorData` 加持久化字段 `animAsset / animDefaultClip / animAutoPlay`；加运行时瞬态字段 `animCurClip / animFrameIndex / animTimeAccum / animPlaying / animSheetPath / animSrc`。
- `LevelDocument.cpp`：`toJson`/`fromJson` 读写三个持久化字段（瞬态不写）。
- `DetailsPanel`：可选组件列表加「动画器」；新增「动画器」折叠区块（选 `.anim`、默认片段下拉、自动播放勾选），按 `components` 含「动画器」显隐。
- Actor 蓝图（`BPClass`）类默认值带这三个字段。

**验证**：给精灵加「动画器」组件、设资源 + 默认片段 + 自动播放，保存关卡再打开，配置仍在。

## 阶段 3 — 编辑态静态预览（渲染源矩形上半部分）

**目标**：场景视口能静态显示角色（默认片段第 0 帧），方便摆放。

- `Viewport2D`：对含「动画器」+ 设了 `animAsset`/`animDefaultClip` 的 Actor，解析 `.anim` 取默认片段第 0 帧源矩形，用 `drawPixmap(目标, sheet, 源矩形)` 画；否则走原 `spritePath`。

**验证**：场景里摆一个配好动画器的精灵，视口显示其向下站立首帧。

## 阶段 4 — 运行时驱动 + 游戏视口动画绘制

**目标**：运行时自动播放循环动画。

- `BPRuntime`：运行起始按 `animAsset` 加载并缓存 `.anim`；`triggerBeginPlay` 对 `animAutoPlay` 的 Actor 设默认片段开播；`tick(dt)` 遍历 `m_actors` 推进帧（累加 / `while` 追帧 / `loop` 决定循环或停末帧）→ 写 `animSheetPath`/`animSrc`；运行起止重置瞬态 + 缓存。
- `GameViewport`：`animSheetPath` 非空 → 画源矩形；否则原 `spritePath`。

**验证**：运行 → 角色循环播放向下行走（≈12FPS，6 帧循环）。

## 阶段 5 — 蓝图节点 `Self.播放动画 / 停止动画`

**目标**：角色 `.bp` 里能切 / 停动画。

- `BlueprintEditor::nodeDefs()`：注册 `Self.Anim.Play`（执行入/出 + `clip` 字符串输入，中文「播放动画」）与 `Self.Anim.Stop`（中文「停止动画」），仅含「动画器」组件的类菜单出现。
- `ActorBPRuntime`：执行两节点 —— Play 设 `animCurClip/animPlaying=true`（切片段才帧归零）；Stop 设 `animPlaying=false`。
- `CLAUDE.md` 术语表：加「播放动画 / 停止动画」节点名、「动画器」组件名。

**验证**：角色 `.bp` 里 `Self.播放动画("walk_right")` 运行时切向右行走；`Self.停止动画` 停在当前帧。完成设计中的端到端验收。
