# 编辑视口 Y 轴翻转设计

> 日期：2026-06-24
> 目标：让编辑视口的 Y 轴方向符合直觉（向上为正），与游戏视图、关卡数据保持一致。

## 背景与问题

关卡数据采用 **Y 向上为正** 的约定（如 `墙_上` 存 `y=+500`，`墙_下` 存 `y=-500`），这与常理一致。

`GameViewport`（游戏视图）渲染时已对 Y 取反（`cameraWorldToScreen` 中 `center.y - (world.y - cam.y)*scale`），因此游戏里 `墙_上` 正确显示在顶部。

但 `Viewport2D`（编辑视口）的坐标换算 **未取反**：

```cpp
QPointF Viewport2D::worldToScreen(QPointF world) const {
    QPointF center(width()/2.0 + m_offset.x(), height()/2.0 + m_offset.y());
    return center + world * m_zoom;          // Y 未翻转 → 向下为正
}
```

导致编辑视口里上下颠倒：`墙_上`（y=500）被画在底部；用户往屏幕上方拖动对象时 Y 反而变成负数，与朝上的绿色 Y 箭头方向矛盾，手动摆放的对象会被存成相反的 Y 值。

**根因：编辑视口画反了，游戏视图与数据约定才是正确的。**

## 方案

仅修改 `launcher/src/editor/Viewport2D.cpp` 的两个坐标换算函数，对 Y 取反，使编辑视口与游戏视图统一为「Y 向上为正」：

```cpp
QPointF Viewport2D::worldToScreen(QPointF world) const {
    QPointF center(width()/2.0 + m_offset.x(), height()/2.0 + m_offset.y());
    return QPointF(center.x() + world.x()*m_zoom,
                   center.y() - world.y()*m_zoom);   // Y 取反
}

QPointF Viewport2D::screenToWorld(QPointF screen) const {
    QPointF center(width()/2.0 + m_offset.x(), height()/2.0 + m_offset.y());
    return QPointF((screen.x() - center.x())/m_zoom,
                   (center.y() - screen.y())/m_zoom); // Y 取反
}
```

### 为什么改这两个函数就够

视口内几乎所有几何都经由这两个函数换算，会随之自动正确：

- **对象渲染位置**：`actorScreenRect` → `worldToScreen` ✅
- **移动拖拽**：`totalDelta = screenToWorld(cur) - m_dragMouseStartWorld` ✅
- **碰撞盒**：`colliderScreenRect` 用 `worldToScreen`；碰撞盒手柄拖拽用 `screenToWorld`，世界 Y 与屏幕上下自洽 ✅
- **范围框（confiner）**：用 `worldToScreen` ✅
- **网格、原点**：用 `worldToScreen`，上下对称 ✅
- **移动/缩放手柄箭头**：在屏幕空间直接绘制、朝屏幕上方（`pos.y() - len`），翻转后「屏幕上」恰好等于「世界 +Y」，方向与数值终于一致 ✅

### 附带修复

`drawActors` 与 `GameViewport` 都用 `p.rotate(a.rotation)` 在屏幕空间旋转。此前编辑视口为 Y-down、游戏视图为 Y-up，同一角度旋转视觉方向相反。本次翻转后两者一致。

### 不在范围内

- **不迁移关卡数据**：数据本就是 Y-up，正确，无需改动。
- **不改物理运行时**：碰撞检测在世界坐标直接运算，与屏幕渲染翻转无关，不受影响。
- 旋转拖拽（横向鼠标位移驱动）与缩放拖拽（已手动反转 dy）不依赖 `worldToScreen`，保持原样。

## 风险

此前**在编辑视口里手动拖放**生成的个别对象，可能已被存成相反的 Y 值，翻转后会上下颠倒，需手动重新摆放。`MyGame/Levels/战斗地图界面.level` 数据经核对正确，预计不受影响。

## 验证

编译后打开 `战斗地图界面`：`墙_上` 应显示在视口**顶部**、细节面板 `y=500`；往上拖动对象 Y 增大；与游戏视图上下一致。
