# 碰撞器系统 + 自定义标签 · 设计

- 日期：2026-06-23
- 状态：已确认，待实现
- 范围：引擎特性。服务于「标准地图界面」的边界与敌人碰撞正规化，替代临时的「是否接近」宏
- 关联：承接 `2026-06-23-标准地图界面-自由走动-design.md`

## 背景

「标准地图界面」第一版用「是否接近」宏（距离平方）判定角色碰敌人，不正规。用户要求按虚幻/Unity 的方式用**碰撞器**实现，并一并解决**边界**（边界=阻挡型碰撞墙）。响应类型确定为**两种：重叠（触发事件）+ 阻挡**。

碰撞过滤用 **Actor 级标签**（复用引擎已有的 `ActorData.tag` + 细节面板标签下拉），不用「图层」（图层归渲染层级）。标签需可**自定义新增**（类似 Unity Add Tag）。

模型取向：**Unity 风**——响应类型 ≈ Unity `isTrigger`，碰撞目标标签 ≈ 层碰撞过滤；不做虚幻式「每通道 忽略/重叠/阻挡 响应矩阵」。

## A. 自定义标签系统（碰撞器的前置）

### 现状
- `ActorData.tag` 已存在（默认「未标记」）。
- `DetailsPanel` 头部已有「标签」下拉（`m_tagCombo`），但选项是**写死的 6 项**：未标记/玩家/敌人/地面/障碍/拾取物。
- 「图层」下拉（`m_layerCombo`）归渲染，**本特性不动它**。

### 改动
- **项目级标签表**：标签列表存入 `{project}/project.json` 的新键 `tags`（字符串数组）。默认含现有 6 项 + 新增「墙」。读写参照 `ProjectSettingsDialog` 对 project.json 的存取。
- **标签下拉数据源**：`m_tagCombo` 从项目标签表填充，不再写死。末尾追加一项 **「添加标签…」**。
- **新增标签交互**：选「添加标签…」弹输入框，输入新标签名 → 写入项目标签表 → 刷新所有标签下拉 → 选中新标签。
- `DetailsPanel` 需能拿到项目根路径（由 `EditorWindow` 注入）以读写 project.json。

### 验收
- 细节面板标签下拉能列出项目标签表的全部标签。
- 「添加标签…」可新增标签（如「墙」），新增后立即可选、并持久化到 project.json，重开项目仍在。

## B. 碰撞器系统

### B1. 数据模型（ActorData 新增碰撞字段）
碰撞盒组件（`碰撞盒`）实际生效，新增字段（`launcher/src/models/LevelDocument.h`，含 toJson/fromJson）：

| 字段 | 含义 | 默认 |
|---|---|---|
| `colliderEnabled` | 启用碰撞盒 | false |
| `colliderW` / `colliderH` | 盒宽/高（世界单位） | 100 / 100 |
| `colliderOffsetX` / `colliderOffsetY` | 相对对象中心的偏移 | 0 / 0 |
| `colliderResponse` | 响应类型："阻挡" / "重叠" | "阻挡" |
| `colliderTargets` | 碰撞目标标签（逗号分隔；空=除自身标签外所有） | "" |

形状：**矩形 AABB**（数据结构为以后加圆形留扩展位，但本期只做矩形）。
对象的"身份"用 **Actor 级 `tag`**，碰撞盒不另存标签。

### B2. 过滤与响应模型
设移动对象 A，其碰撞盒 `colliderTargets` 命中对象 B 的 `tag`，且 A、B 的盒相交：
- **B.colliderResponse == 阻挡** → A 被挡住（见 B3 分轴解析）。
- **B.colliderResponse == 重叠** → 触发 A 的「碰撞时」事件，带上 B（见 B4）。

要点：**响应类型描述「别人撞到我时的反应」**（墙=阻挡、敌人=重叠）；**目标标签描述「我主动检测谁」**（角色=`墙,敌人`）。敌人之间不互相检测 → 不互碰。

### B3. 阻挡解析：分轴
每帧在所有移动逻辑执行完后，对每个"启用且有目标"的碰撞盒对象 A：
- 记录 A 的上一帧位置 `prev`，当前位置 `cur`。
- **分轴回退**：
  1. 试 X：位置 = (cur.x, prev.y)。若与任一命中的「阻挡」盒相交 → X 取 prev.x，否则取 cur.x → `rx`。
  2. 试 Y：位置 = (rx, cur.y)。若相交 → Y 取 prev.y，否则取 cur.y → `ry`。
  - 最终 A = (rx, ry)。
- 效果（与用户确认一致）：单键撞垂直墙→顶停；组合键（W+A 等）→ 沿墙滑动。

运行时为每个对象维护 `prevX/prevY`（每帧解析后更新）。

### B4. 重叠 +「碰撞时」事件节点（新增）
- 新增事件节点 typeId `Event.OnCollision`，中文 **碰撞时**，header 事件紫。
- 输出引脚：`对方对象`（ActorRef，对方 Actor id）、`对方标签`（字符串）。
- 关卡蓝图与 Actor 蓝图都支持（`BPRuntime` 与 `ActorBPRuntime` 各自分发）。
- 触发时机：碰撞 pass 检测到 A 与「重叠」盒 B 相交，对 A 所属蓝图触发 `碰撞时`，`对方对象`=B、`对方标签`=B.tag。
- 去抖：同一对 (A,B) 持续重叠时每帧都会满足；本期**每帧触发一次**（足够驱动「碰到敌人就跳转」）。是否做 Enter/Exit 边沿留后续。

**前置补丁：Actor 蓝图支持「跳转关卡 / 返回上一关」**
现状 `ActorBPRuntime` 不处理 `Action.LoadLevel` / `Action.BackLevel`。而「碰撞时」事件在角色自己的蓝图（`角色.bp`，Actor 蓝图）里触发，需要在那里就能跳转。改动：`ActorBPRuntime::executeNode` 增加这两个节点，转为发信号（如 `loadLevelRequested` / `backLevelRequested`），由 `EditorWindow` 接到与关卡蓝图相同的换关处理。属 Actor 蓝图一等公民化的延续。

### B5. 细节面板 UI
`碰撞盒` 组件区块（仅当对象含「碰撞盒」组件时显示）编辑：启用、宽、高、偏移X、偏移Y、响应类型（下拉：阻挡/重叠）、碰撞目标标签（可多选已存在标签，或文本逗号分隔）。用 `QSignalBlocker` 包裹赋值，沿用现有细节面板模式。

### B6. 视口绿框 + 拖拽手柄（Viewport2D）
- 选中对象时，按 `collider*` 字段在视口画**绿色矩形轮廓**（世界→屏幕换算，随 zoom/offset）。
- 框的**四边中点 + 四角**带拖拽手柄：拖角改宽高，拖边改单轴宽高，拖框内部移动偏移。命中检测与拖拽仿照现有 `ScaleHandle`（`Viewport2D` 已有 AxisX/AxisY/Center 手柄基础）。
- 拖拽实时写回 `colliderW/H/OffsetX/OffsetY` 并刷新细节面板。

### B7. 运行时碰撞 pass
- 在每帧**所有移动逻辑（关卡蓝图 + 各 Actor 蓝图 tick）执行完之后**统一跑一遍碰撞 pass（顺序：移动 → 分轴阻挡解析 → 重叠事件分发）。
- 由 `BPRuntime` 持有 pass（它掌握全部 actor 列表 `m_actors`）；`EditorWindow` 帧循环在 actor 蓝图 tick 后调用。
- AABB 相交：用对象世界位置 + 偏移 + 宽高算两矩形是否相交。

## 内容改动（MyGame）
- 新增标签「墙」。
- `角色.bp` / 角色实例：加碰撞盒（响应=阻挡，目标=`敌人,墙`，尺寸贴合精灵）。
- `敌人.bp`：加碰撞盒（响应=重叠，目标空）；Actor 标签设「敌人」。
- 地图加 **4 面墙**（Empty/Sprite + 碰撞盒，响应=阻挡，标签「墙」），围出边界。
- `角色.bp`：用 `碰撞时`（对方标签==敌人 → `跳转关卡` 战斗）替换原关卡蓝图的接触跳转逻辑。
- **退役 `是否接近.bpmacro`** 与关卡蓝图里的接触检测节点。

## 影响文件
引擎：
- `models/LevelDocument.h/.cpp`：ActorData 碰撞字段 + 序列化；`prevX/prevY` 运行期字段。
- `editor/ProjectSettingsDialog.*` 或新建小工具：project.json `tags` 读写。
- `editor/DetailsPanel.*`：标签下拉数据源 +「添加标签…」；碰撞盒组件 UI；注入项目根路径。
- `editor/Viewport2D.*`：绿框绘制 + 碰撞盒拖拽手柄。
- `editor/BlueprintEditor.cpp`：注册 `Event.OnCollision` 节点。
- `editor/BPRuntime.*` / `editor/ActorBPRuntime.*`：碰撞 pass、分轴解析、`碰撞时` 事件分发与输出引脚求值；`ActorBPRuntime` 补 `Action.LoadLevel/BackLevel`（发信号给 EditorWindow）。
- `editor/EditorWindow.cpp`：帧循环在移动后调用碰撞 pass。

## 不做（明确排除）
- 圆形碰撞器（留扩展位，本期只矩形）。
- 虚幻式响应矩阵（每通道 忽略/重叠/阻挡）。
- 碰撞 Enter/Exit 边沿事件（本期重叠每帧触发一次）。
- 刚体/物理（速度、反弹、质量）。
- 旋转碰撞盒（仅 AABB，不随对象旋转）。
- 角色动画按 `角色` 变量切换（用户反馈第 1 点）——独立小特性，本 spec 之后单独做「设置动画资产」节点。

## 构建顺序
1. 自定义标签系统（A）——独立可测。
2. 碰撞数据模型 + 序列化（B1）。
3. 细节面板碰撞盒 UI（B5）+ 视口绿框与手柄（B6）——可视化先行，便于摆盒子。
4. 运行时碰撞 pass：分轴阻挡（B3）。
5. `碰撞时` 事件节点 + 重叠分发（B4）。
6. 内容接入：角色/敌人/墙碰撞盒、角色.bp 用碰撞时、退役「是否接近」。
