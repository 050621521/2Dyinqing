# 移动项目到新位置 — 设计文档

日期：2026-06-23

## 背景

项目浏览器（`LauncherWindow`）中，最近打开的项目以卡片形式展示。当前底部「项目位置」字段为只读，右键菜单只有「从列表中移除」与「彻底删除项目文件夹…」，用户无法把已创建的项目移动到磁盘上的其他位置。

本功能为项目卡片增加「移动到…」操作：真正把整个项目文件夹从当前位置移动到用户选定的新父目录，并同步更新最近列表中的路径记录。

## 目标

- 在项目卡片右键菜单新增「移动到…」入口。
- 真正移动磁盘上的项目文件夹（剪切语义，原位置不再保留文件）。
- 移动后自动更新 `projects.json` 中该项目的路径记录并刷新界面。
- 跨磁盘卷场景也能正常工作。

## 非目标（YAGNI）

- 不在此功能中修改项目名称。
- 不支持重命名文件夹（保持原文件夹名，只换父目录）；重命名是独立功能。
- 不处理项目正被编辑器打开的情况（项目浏览器界面下项目尚未打开）。

## 用户交互

1. 在项目卡片上右键 → 菜单中「从列表中移除」**上方**新增一项「移动到…」。
2. 点击后弹出系统目录选择对话框（`QFileDialog::getExistingDirectory`），标题「选择移动到的目标位置」，默认定位到项目当前所在的父目录。
3. 用户选定目标父目录后执行移动；成功后网格刷新，底部「项目位置」显示新路径。
4. 出错时弹 `QMessageBox` 告知原因，不更新记录。

## 实现设计

### ProjectCard（入口）

`contextMenuEvent` 中，在 `removeAct` 之前插入：

```cpp
QAction* moveAct = menu.addAction("移动到…");
menu.addSeparator();
QAction* removeAct = menu.addAction("从列表中移除");
```

选中 `moveAct` 时 `emit moveRequested(m_info);`。头文件新增信号 `void moveRequested(const ProjectInfo& info);`。

### ProjectGrid（信号透传）

- 头文件新增信号 `void moveRequested(const ProjectInfo& info);`
- 在 `rebuild()` 内连接每张卡片：
  ```cpp
  connect(card, &ProjectCard::moveRequested, this, [this](const ProjectInfo& info) {
      emit moveRequested(info);
  });
  ```

### LauncherWindow（处理逻辑）

`setupUi()` 中连接 `m_grid` 的 `moveRequested` 到新槽 `onMoveProject(const ProjectInfo&)`。

`onMoveProject` 流程：

1. `QString folderName = QDir(info.path).dirName();`
2. `QString parentDir = QFileInfo(info.path).absolutePath();`（作为对话框默认目录）
3. `QString chosenDir = QFileDialog::getExistingDirectory(this, "选择移动到的目标位置", parentDir);`，为空则返回。
4. `QString newPath = QDir(chosenDir).filePath(folderName);`
5. 校验：
   - `QDir(newPath) == QDir(info.path)`（同一目录）→ 直接返回，不提示。
   - `QFileInfo::exists(newPath)` → 弹错误「目标位置已存在同名文件夹」，中止。
6. 执行移动（见下）。失败 → 弹错误「移动失败」，中止。
7. 成功 → `ProjectManager::instance().updateProjectPath(info.path, newPath);` 然后 `loadData();`

#### 移动实现

```cpp
bool moveDir(const QString& src, const QString& dst) {
    if (QDir().rename(src, dst)) return true;          // 同卷瞬间完成
    if (!copyRecursively(src, dst)) return false;       // 跨卷回退：复制
    return QDir(src).removeRecursively();               // 删除原文件夹
}
```

`copyRecursively(src, dst)`：递归创建目录、`QFile::copy` 文件。若跨卷复制中途失败，已复制的部分残留在目标位置（保持简单，不做回滚），但原文件夹不删除，记录也不更新，用户数据不丢失。

### ProjectManager（数据层）

头文件新增：`void updateProjectPath(const QString& oldPath, const QString& newPath);`

实现：

```cpp
void ProjectManager::updateProjectPath(const QString& oldPath, const QString& newPath) {
    for (auto& p : m_recent) {
        if (p.path == oldPath) { p.path = newPath; break; }
    }
    save();
}
```

`name` 不变（文件夹名未变）。

## 错误处理

| 情况 | 行为 |
|---|---|
| 用户取消目录选择 | 静默返回 |
| 选中目录与原目录相同 | 静默返回 |
| 目标已存在同名文件夹 | 弹错误，中止 |
| 移动（rename + 复制回退）失败 | 弹错误「移动失败」，原文件与记录保持不变 |
