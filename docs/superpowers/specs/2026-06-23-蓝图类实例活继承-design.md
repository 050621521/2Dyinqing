# 蓝图类 → 实例 活继承（属性覆盖）· 设计

- 日期：2026-06-23
- 状态：已确认，待实现
- 范围：让场景实例「跟随」其蓝图类的默认值，改类即改未覆盖实例（虚幻 CDO 式）

## 背景

当前「类→实例」是**拍快照**：拖放生成实例时把类的组件 + 默认值拷进实例自己的 `ActorData`，之后改类，已摆放实例不跟随。用户期望虚幻式**活继承**：改类默认值，所有未单独覆盖该属性的实例立即跟随。

## 模型（对齐虚幻 CDO + 逐属性覆盖）

**虚幻不硬分类字段**：每个属性都「跟随类默认，除非实例覆盖」。位置看似永远归实例，只是因为摆放即覆盖位置。

- **身份字段 `id` / `name`**：实例独有，不参与继承。
- **其余全部字段**（位置、旋转、缩放、标签、图层、激活、精灵渲染器、动画器…）：**跟随类默认，除非被实例覆盖**。
- **组件列表**：跟随类（类加「动画器」，实例即有）；本轮实例不单独增删组件。

## 数据模型

`ActorData` 新增：
```cpp
QSet<QString> overriddenFields;   // 已覆盖的字段名（用 toJson 的键名，如 "scaleX"/"animAsset"）
```
- 持久化：`toJson` 写为字符串数组，`fromJson` 读回。
- **向后兼容**：旧关卡的实例 JSON **没有** `overriddenFields` 键 → 视为「全部字段已覆盖」（保持其快照值不变，不因引入本特性而突变）。

字段名约定：复用 `ActorData::toJson` 的键（`x`/`y` 合记为 `position`；`scaleX`/`scaleY` 合记为 `scale`；`rotation`；`spritePath`；`animAsset` 等）。为简化，覆盖以「逻辑字段」为粒度：`position`、`scale`、`rotation` 各为一个整体键。

## 类默认值存储调整

`applyActorToBpClass`（类编辑写回）此前剔除了 `position/rotation/scale`。改为**只剔除 `id/name/bpClass/position`**——保留 `rotation/scale` 及全部组件字段为可继承的类默认值（位置无类默认意义，仍剔除）。

内置类（`builtin/*`）`defaults` 为空 → 解析时无可继承项 → 实例保持自身值，行为不变（向后兼容）。

## 核心：解析（bake）

`resolveInstanceFromClass(ActorData& inst, const BPClass& cls)`：
- `inst.components = cls.components`（组件跟随类）。
- 对 `cls.defaults` 的每个字段键 `k`：若 `k ∉ inst.overriddenFields`，把类默认值写入 `inst` 对应字段（经 `toJson/fromJson` 键映射）。
- `position`（x/y）：类默认里已无此键，天然保持实例值。
- `id/name/overriddenFields/bpClass` 保持不变。

实现手法（复用 JSON）：
```
QJsonObject j = inst.toJson();
for (k, v) in cls.defaults:
    if (!inst.overriddenFields.contains(logicalKeyOf(k)))
        j[k] = QJsonValue::fromVariant(v);
j["components"] = cls.components;
ActorData r = ActorData::fromJson(j);
r.overriddenFields = inst.overriddenFields;  // 保留
inst = r;
```

## 触发时机

1. **关卡加载后**：对每个 `bpClass` 非 builtin 的实例，加载其类并 `resolveInstanceFromClass`。
2. **类编辑器改了类默认值**（`applyActorToBpClass` + `save` 之后）：遍历所有打开关卡里属于该类的实例，重新解析 → 刷新大纲/视口 → 标脏。
3. **拖放生成实例**：用类默认 + 组件构造实例；`overriddenFields = {"position"}`（仅位置算覆盖，其余跟随类）。

## 覆盖标记（实例编辑）

`EditorWindow` 的 `DetailsPanel::actorModified` 处理已有 `before`/`after`。在其中**逐字段对比**：
- 任一逻辑字段（`scale`/`rotation`/`spritePath`/`animAsset`/…）发生变化 → 加入 `after.overriddenFields`。
- `id/name` 不计入（身份字段）。
- 仅对 `bpClass` 非 builtin 的实例做此标记（builtin 实例无类可继承，全部视为自有）。

## 编辑器交互

- 类编辑器改默认值后实例实时刷新（时机 2）。
- 本轮**不做**「重置为类默认」（清除单个覆盖）的 UI——留待后续（虚幻的黄色复位箭头）。

## 验收

1. 场景放两个「武夫」实例，都不碰缩放。改 `武夫.bp` 的缩放为 2 → 两个实例都变 2 倍。
2. 单独把实例 A 缩放调成 3。再改类缩放为 1 → 实例 B 跟随变 1，实例 A 保持 3（已覆盖）。
3. 类加「动画器」+ 设动画资源 → 已摆放实例自动获得动画器并能播放。
4. 旧关卡（无 `overriddenFields`）的实例保持原值不突变。

## 不做（YAGNI）

- 嵌套类 / 类继承类。
- builtin 类的可编辑默认值。
