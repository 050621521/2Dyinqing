# 函数式封装（纯函数 / 返回值）设计文档

日期：2026-06-16
状态：方向已确认（照虚幻 Function，聚焦纯函数），待评审

## 背景与动机

宏式自定义节点（已完成）封装的是**执行流**——内联、共享上下文、多出口，但**不返回值、无局部作用域**。

游戏里还有大量"**给几个输入、算出一个值返回**"的可复用纯逻辑：伤害公式（攻击×倍率−防御）、距离判断、取最大值等。这正是虚幻 **纯函数（Pure Function）** 的领域：一个**数据节点**，输出在被读取时按需计算。本子项目补上这一块。

依赖：复用已完成的[宏式封装]基础设施（`BPMacro`、入口/出口节点、子图编辑、库资产列表、调用节点动态引脚）。

## 虚幻先例

- 函数 = 独立图，单执行入口 + 返回节点；输入/返回值带类型；有独立作用域和局部变量。
- **纯函数**：无执行引脚，是数据节点，输出"被读取时计算"。封装算值逻辑。
- 与宏分工：宏管执行流（多出口/循环、共享上下文），函数管算值/返回（独立作用域、纯函数当数据用）。

本设计照搬"纯函数 = 数据节点、读取时求值"的核心。

## 目标与范围（v1：纯函数）

**做：**
1. **函数资产**：输入数据参数 + 返回数据值 + 内部数据流子图（无执行引脚）。
2. **创建**：框选数据节点 →「折叠为函数」；右键"自定义函数"菜单放置；双击进子图编辑（复用宏编辑）。
3. **调用节点**：**纯数据节点**（无 exec），输出 = 返回值；读取输出时求值。
4. **运行时**：解释器在**数据求值**层支持"读函数调用节点输出 → 进子图算返回值"（含输入映射）。

**不做（后续）：**
- **局部变量**（v1 纯函数是无状态数据流；局部变量后续叠加）。
- **非纯函数**（带 exec、有副作用）——先只做纯函数。
- 递归函数（防自引用，编辑期禁止）。

## 数据模型：复用 BPMacro + kind

给 `BPMacro` 增加 `kind` 字段：`"macro"`（默认）/ `"function"`。函数复用同一结构（id/name/inputPins/outputPins/nodes/connections + 入口/出口节点）：

- 函数的 `inputPins` / `outputPins` 全是**数据引脚**（`isExec=false`），无 exec。
- 存盘：函数存 `{project}/Blueprints/Functions/*.bpfunc`（与宏的 `Macros/*.bpmacro` 分目录），`toJson` 写 `kind`。
- `BPMacro::listFunctions(projectRoot)` 枚举 Functions 目录。

调用节点 `type = "Func::<id>"`（区别于宏的 `Macro::<id>`）。

## 引脚与显示（复用动态引脚）

- `effectivePins` 对 `Func::` 调用节点：取函数 `inputPins`（数据输入）+ `outputPins`（数据输出），**全部非 exec**。
- `drawNode` 标题：函数名；header 用区别色（如绿松 `#2a5a4a`）。
- 入口节点输出 = 函数 inputPins（数据）；出口节点输入 = 函数 outputPins（返回值）。复用 `Macro.Entry/Macro.Exit`（编辑时 `m_editingMacro` 提供接口）。

## 创建：折叠为函数

在现有折叠交互上加一个入口：选区右键 →「**折叠为函数**」（与「折叠成节点」=宏 并列）：
- 只把**数据**边界引脚纳入函数接口（穿入数据→输入参数，穿出数据→返回值）；**exec 穿越的连线不纳入**（纯函数无执行流）。若选区有 exec 穿越，提示"纯函数不含执行流，将忽略 exec 连线"。
- 产出本地函数（`Func::local`，子图存 `params["subgraph"]`，kind=function）；可右键「提升为函数库资产」写成 `.bpfunc`（复用宏的提升逻辑）。

## 运行时：数据流求值（核心）

宏靠装载时 flatten（执行流内联）；**函数不 flatten**，而是在 `resolveOutputPin` 读到 `Func::` 调用节点输出时**按需求值**：

```
resolveOutputPin(funcCallNode, outPinKey):
  解析函数（本地 subgraph 或库 .bpfunc）
  建临时上下文：函数内部节点/连线 + 一张"入口输入值"表
    入口某输入引脚的值 = 调用节点对应输入引脚的外部解析值（resolveDataPin 到调用节点）
  求 outPinKey 对应的返回：解析"出口节点该返回引脚"的数据输入
    —— 在函数子图内做数据解析（resolveDataPin/resolveOutputPin 的子图版），
       遇到入口节点的输出引脚 → 返回入口输入值表里的值
  返回算得的值
```

- 实现：给求值函数加一个"当前函数帧"（子图 nodes/conns + 入口值表 + 防递归深度）。`resolveDataPin/resolveOutputPin` 在帧内对子图求值；不在帧内时走原关卡图。
- 纯函数无副作用、无 exec：只读数据、算值返回，安全。
- 嵌套：函数里可调用别的函数（帧栈）；编辑期禁止自引用、运行期深度上限兜底。

## 影响文件

- `launcher/src/models/BPMacro.h/.cpp`：`kind` 字段 + `listFunctions` + Functions 目录。
- `launcher/src/editor/BlueprintEditor.*`：`Func::` 调用节点 effectivePins/标题/容忍；折叠为函数（数据边界）；右键"自定义函数"菜单 + "提升为函数库资产"；双击编辑复用宏编辑（kind=function 时入口/出口为纯数据）。
- `launcher/src/editor/BPRuntime.*`：函数子图按需数据流求值（函数帧栈 + 入口值映射 + 防递归）。
- `CLAUDE.md`：术语 `Func::* → 自定义函数`。

## 验证

1. 框选"攻击×倍率−防御"数据节点 → 折叠为函数"算伤害"，得一个**纯数据调用节点**（无 exec），输出=结果。
2. 在别处放"算伤害"，给输入接值，把输出接到"设置数值变量"等 → 运行得到正确结果。
3. 提升为函数库资产；别的蓝图右键"自定义函数"放置使用。
4. 双击进函数编辑、改公式 → 调用处结果随之变化。
5. 函数里调用另一个函数（嵌套）正确；自引用被阻止。
6. 存档/重开还原。
