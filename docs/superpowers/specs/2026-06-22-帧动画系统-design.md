# 帧动画系统 · 设计

- 日期：2026-06-22
- 状态：已确认，待实现
- 范围：为引擎新增「精灵帧动画」能力，服务俯视角角色移动等场景

## 背景

引擎目前精灵对象只能显示**一张静态图片**（`ActorData.spritePath` → `QPixmap`），没有任何动画概念。手上已有成套素材：俯视角 8 方向行走动画（每方向 6 帧、单帧 64×64、12 FPS、循环），同时提供**精灵表**（一张 8 行 ×6 列大图）、**拆好的单帧**，以及描述网格与方向的**元数据 JSON**（`角色动画/43_001_武夫_移动_元数据.json`）。素材是初步的，后续方向数 / 帧数会变（如 8 方向 ×8 帧），系统必须**不写死方向数和帧数**。

本设计对齐两个参照：
- **Unity 的 2D 动画管线**：一张纹理 + 每帧一个源矩形（不物理切图）；动画片段 = 一串帧引用 + 时序；Animator 是状态机（本期不做）。
- **本引擎的心智模型**：资源 / 组件 / 蓝图节点 / 关卡蓝图 四层各归各位。

## 设计决策（已与用户确认）

| 决策点 | 结论 |
|---|---|
| 动画类型 | 帧动画（序列帧 / 精灵表） |
| 运行时加载形式 | 精灵表 + 源矩形（Unity 式，一张图只加载一次，每帧画子矩形，不切片复制） |
| 动画定义存放 | 独立**动画资源文件 `.anim`**（可多对象共用） |
| 动画能力的载体 | 新增**「动画器」组件**，与「精灵渲染器」并列，挂在精灵对象上 |
| 播放控制位置 | 角色**自己的 Actor 蓝图**，用 `Self.*` 节点控制 |
| 动画状态机 | **本期不做**，但数据结构留好路（状态机的状态即这些 Clip） |
| 切片 / 预览窗口 | **本期不做**（依赖元数据 JSON 或导入对话框提供网格） |

## 数据模型（三层）

### 资源：动画资源文件 `.anim`（JSON）

存于项目内（如 `{project}/Animations/武夫.anim` 或随素材目录），纯数据、可被多个对象 / 多关卡共用。结构：

```json
{
  "sheet": "角色动画/43_001_武夫_移动_精灵表.png",
  "frameW": 64,
  "frameH": 64,
  "cols": 6,
  "rows": 8,
  "clips": [
    { "name": "walk_down",  "label": "下",  "row": 0, "startCol": 0, "frameCount": 6, "fps": 12, "loop": true },
    { "name": "walk_right", "label": "右",  "row": 2, "startCol": 0, "frameCount": 6, "fps": 12, "loop": true }
  ]
}
```

- **Clip 寻址方式**：`row` + `startCol` + `frameCount`，帧沿该行从 `startCol` 起连续取 `frameCount` 个格子。`startCol` 默认 0。这种「行号 + 帧数」寻址足以覆盖 8 方向 ×6/×8 等规整精灵表，且不写死方向数 / 帧数。
- 不规整精灵表的「显式逐帧 (col,row) 列表」留作后续扩展，本期不做。
- `sheet` 为相对项目根的路径。

新增 `src/models/AnimationAsset.h/.cpp`：
- 结构体 `AnimClip { QString name, label; int row, startCol, frameCount; double fps; bool loop; }`
- 结构体 `AnimationAsset { QString sheet; int frameW, frameH, cols, rows; QList<AnimClip> clips; }`
- `bool load(const QString& path)` / `bool save(const QString& path)`（`QJsonDocument` 读写，与现有持久化一致）
- `const AnimClip* findClip(const QString& name) const`
- 计算单帧源矩形的辅助：给定 clip + 帧序号 → `QRect`（`x = (startCol+frameIndex)*frameW`，`y = row*frameH`，`w/h = frameW/frameH`）

### 组件：「动画器」

与「精灵渲染器」并列的新组件，挂在精灵对象上，表示「会播动画」这一能力。**依赖「精灵渲染器」**：动画器播放时，当前帧覆盖精灵原本显示的 `spritePath`。

`ActorData` 新增 3 个**持久化**字段（沿用「精灵渲染器」字段的内联存储方式，见 `LevelDocument.h` 第 25–33 行附近）：

```cpp
// 动画器组件属性
QString animAsset;          // 引用的 .anim 路径（相对项目根），空 = 无动画
QString animDefaultClip;    // 默认播放片段名（如 "walk_down"）
bool    animAutoPlay = true;// 开始运行即自动播放默认片段
```

- 在 `ActorData::toJson` / `fromJson` 中读写这三个字段。
- 组件挂载：`DetailsPanel` 的可选组件列表（`DetailsPanel.cpp` 第 115 行 `all` 列表）加入「动画器」；`components` 含「动画器」时显示对应区块。
- Actor 级蓝图（`BPClass`，`.bp`）的类默认值同样需带这三个字段，沿用精灵渲染器组件默认值的存储路径。

### 运行时瞬态状态（不序列化）

动画播放的中间状态，运行期临时记录在 `ActorData` 快照上（两套运行时都通过共享的 `m_actors` 快照访问 Actor，存这里最省事），**不写入 `toJson`**：

```cpp
// 运行时瞬态（不持久化）
QString animCurClip;        // 当前播放片段名
int     animFrameIndex = 0; // 当前帧序号（clip 内）
double  animTimeAccum  = 0; // 帧计时累加（秒）
bool    animPlaying    = false;
QString animSheetPath;      // 解析出的精灵表绝对路径（供视口绘制）；空 = 不走动画绘制
QRect   animSrc;            // 当前帧源矩形
```

## 控制节点（蓝图）

`Self.*` 系列，仅在含「动画器」组件的 Actor 蓝图（`bpClass` 模式）右键菜单中出现（沿用 `BlueprintEditor` 按类组件过滤 `Self.*` 分类的现有机制）。

| typeId | 中文名 | 引脚 | header 色 |
|---|---|---|---|
| `Self.Anim.Play` | 播放动画 | 执行入 / 执行出 / `clip`（数据输入，字符串，中文名「片段名」） | 与其他 `Self.*` 一致 |
| `Self.Anim.Stop` | 停止动画 | 执行入 / 执行出 | 同上 |

在 `BlueprintEditor::nodeDefs()` 注册这两条；中文名同步进 `CLAUDE.md` 术语表。

> 角色在自己的 `.bp` 里写：`每帧 → 条件分支判断方向 → Self.播放动画("walk_right")`。蓝图本身充当「代码式状态机」。

## 运行时驱动

**控制权在 `ActorBPRuntime`（设置播哪个片段），帧推进集中在 `BPRuntime::tick`（统一步进）。**

### Self 节点执行（`ActorBPRuntime`，self = 该 Actor）

- `Self.播放动画(clip)`：设 `animCurClip = clip`、`animPlaying = true`；若切换到了不同片段，则 `animFrameIndex = 0`、`animTimeAccum = 0`（同片段重复调用不打断，避免每帧归零卡在第 0 帧）。
- `Self.停止动画`：`animPlaying = false`（停在当前帧，不归零）。

### 帧推进（`BPRuntime::tick(dt)`）

`tick` 已每帧遍历 `m_actors`（见 `BPRuntime.cpp`）。在其中对每个 `animPlaying` 且 `animAsset` 非空的 Actor：
1. 取该 Actor 的 `.anim` 资源（运行起始时按 `animAsset` 路径加载并缓存，避免每帧读盘）与当前 clip。
2. `animTimeAccum += dt`；当 `animTimeAccum >= 1.0/fps` 时步进：`animFrameIndex++` 并扣减累加值（用 `while` 支持低帧率追帧）。
3. 到末帧：`loop` 为真则回 0；否则停在末帧并 `animPlaying = false`。
4. 用资源的源矩形辅助算出 `animSrc`，`animSheetPath` 设为精灵表绝对路径。
5. `tick` 末尾照旧 `emit stateChanged()` → 视口刷新。

### 生命周期

- `triggerBeginPlay`：对 `animAutoPlay` 且有 `animDefaultClip` 的 Actor，设 `animCurClip = animDefaultClip`、`animPlaying = true`、帧 / 计时归零。
- 运行起 / 止：清空 / 重置全部动画瞬态状态与 `.anim` 缓存（与现有 `m_heldKeys` 等运行态一并处理）。

## 渲染（Unity 式：一张图 + 源矩形）

精灵表只进 `m_pixmapCache` 一次。在 `GameViewport`（运行时，绘制点见 `GameViewport.cpp` 第 210 行附近）与 `Viewport2D`（编辑时）的精灵绘制处：

```cpp
if (!a.animSheetPath.isEmpty()) {
    const QPixmap& sheet = cached(a.animSheetPath);
    p.drawPixmap(目标矩形, sheet, a.animSrc);   // 画当前帧子矩形
} else if (!a.spritePath.isEmpty()) {
    p.drawPixmap(目标矩形, cached(a.spritePath)); // 原静态精灵路径
}
```

- **目标矩形尺寸**：仍按现有逻辑（按单帧像素尺寸 / PPU 换算），`flipX/flipY`、`spriteColor` 等现有处理继续生效。
- **编辑时静态预览**：`Viewport2D` 对含「动画器」且设了 `animAsset` + `animDefaultClip` 的 Actor，静态显示**默认片段第 0 帧**的源矩形，方便摆放查看（非运行态不推进帧）。需在编辑态也能解析 `.anim` 取首帧源矩形。

## 编辑器 UI

### 内容浏览器（`ContentBrowser`）

- 新增**「导入动画」**按钮（与第 97 行「导入图片」并列）：
  1. 选一张精灵表 png。
  2. 自动在同目录找同名 / 关联的元数据 JSON：找到 → 解析网格与每行方向，生成全部 clip；找不到 → 弹简单对话框填 `frameW/frameH/cols/rows`，默认「每行一个 clip、整行帧数、12 FPS、循环」。
  3. 产出 `<名称>.anim` 写入当前目录。
- 资源类型：新增 `type == "anim"`（参照第 429 行 `m_currentTypes` 与第 448–458 行图标 / 标签分支），网格中以专属图标显示，可重命名（第 215 行附近后缀分支加 `.anim`）。

### 细节面板（`DetailsPanel`）

- 新增「动画器」折叠区块（结构沿用 `buildSpriteRenderer`，第 729 行）：
  - **动画资源**：选择 `.anim` 文件（类似 `assignSpritePath` 的选择交互）。
  - **默认片段**：下拉，列出所选 `.anim` 的全部 clip 名。
  - **自动播放**：勾选。
- 按 `components` 是否含「动画器」显示 / 隐藏（参照 `refreshSpriteSection`，第 476 行）。

### 不做

不做独立的切片窗口（Sprite Editor 等价物）与动画预览播放器窗口。

## 端到端验收（本 spec 自包含）

1. 在内容浏览器「导入动画」选武夫精灵表 → 自动读元数据 JSON → 生成含 8 个方向 clip 的 `武夫.anim`。
2. 给一个精灵对象加「动画器」组件，动画资源 = `武夫.anim`，默认片段 = `walk_down`，勾选自动播放。
3. 运行 → 该对象循环播放向下行走动画（每 ≈1/12 秒换帧，6 帧循环）。
4. 在该角色的 `.bp` 里用 `Self.播放动画("walk_right")` → 运行时切到向右行走动画。
5. `Self.停止动画` → 停在当前帧。
6. 编辑态视口静态显示默认片段第 0 帧。

> **依赖说明（不在本 spec 内）**：完整「WASD 驱动 8 方向行走」还需 Actor 蓝图能每帧读输入。`每帧`（`Event.Tick`）在 `ActorBPRuntime` 已支持；`持续按住` 目前仅关卡蓝图运行时支持——把它扩到 `ActorBPRuntime` 属于《自由走动地图引擎需求》spec 的延伸工作。本动画 spec 只保证「动画能被 `Self` 节点正确播放 / 切换 / 渲染」。

## 明确不做（YAGNI）

- 完整动画状态机（状态图编辑器 / 参数 / 转换求值 / 混合树）——留好路，状态即 Clip。
- 时间轴 / 关键帧编辑、属性补间（Tween）。
- 动画事件、动画混合、根运动。
- 手动切片窗口与独立预览播放器。
- 不规整精灵表的显式逐帧寻址。
- `ActorBPRuntime` 的「持续按住」改造（归属另一份 spec）。
