# 2D 引擎开发路线图

> 更新日期：2026-06-11　｜　工作日 4h/天，周末 8h/天，每周约 **36h**

---

## 一、现状速览

### ✅ 已完成

| 模块 | 说明 |
|---|---|
| 项目管理 / 场景编辑器 | 完整，含多关卡 Tab、布局保存 |
| 精灵渲染 / 摄像机 / 变换 | 完整，含 PPU、Flip、Tint、平铺 |
| 跟随控制 / 边界限制组件 | BPRuntime 已实现，可在运行时生效 |
| 蓝图编辑器（可视化） | 节点连线、内联编辑、弹出菜单可用 |
| 运行时（BPRuntime） | 16ms tick，BeginPlay / KeyDown / Tick 事件 |
| 关卡存取 | JSON 持久化，脏标记，关闭前提示 |

### 🔴 缺失（没有就做不了游戏）

| 缺失项 | 影响 |
|---|---|
| **持续按键检测**（KeyHeld） | 现在只有 KeyDown 触发一次，角色无法持续移动 |
| **碰撞检测系统** | 物体互穿，无 Overlap 事件，游戏逻辑无从建立 |
| **BP 数学节点** | 无法做加减乘除比较，蓝图逻辑极度受限 |
| **BP 变量存储** | 无法记录分数、血量等运行时状态 |
| **游戏内 UI**（文字 / 分数） | 运行时无法显示任何 HUD |
| **关卡切换 / 重启** | 游戏无法正常结束和重开 |
| **音频系统** | 没有任何音效或背景音乐 |
| **精灵动画** | 所有角色均为静态图片 |
| **游戏导出**（独立 .app） | 只能在编辑器里跑，无法发布 |

## 三、每日任务计划

---

### Phase 1 · 输入 + BP 节点扩展

#### `June 11`（周三，4h）— 持续按键检测

- `BPRuntime` 加 `m_heldKeys` 集合
- `EditorWindow` 同时传递 `keyPress` / `keyRelease` 事件给运行时
- 新节点：`Event.KeyHeld`（每 tick 持续触发）、`Event.KeyUp`
- `BlueprintEditor` 注册两个新节点定义

#### `June 12`（周四，4h）— BP 数学节点

- 新节点：`Math.Add`、`Math.Sub`、`Math.Mul`、`Math.Div`
- 新节点：`Math.Clamp(value, min, max)`、`Math.Compare(a, b) → bool`
- `BPRuntime::executeNode` / `resolveOutputPin` 加入对应逻辑

#### `June 13`（周五，4h）— BP 变量 + 动作节点

- 新节点：`Var.SetFloat/GetFloat`、`Var.SetInt/GetInt`（存于 `BPRuntime::m_vars`）
- 新节点：`Action.SetActorPos(actorId, x, y)`（绝对坐标设置）
- 新节点：`Action.DestroyActor(actorId)`、`Var.FloatToString`、`Var.IntToString`

#### `June 14`（周六，8h）— 节点测试 + 边界补全

- 搭测试蓝图：`KeyHeld → Math.Mul(dx, dt) → MoveActor`，验证帧率无关移动
- 补充：`Var.RandomFloat(min, max)`、`Math.Abs`、`Math.Negate`
- 修复发现的 bug

---

### Phase 2 · 碰撞系统

#### `June 15`（周日，8h）— 碰撞数据结构 + 可视化

- `ActorData` 新增字段：`colliderEnabled`、`colliderW/H`、`isTrigger`、`collisionLayer`
- `DetailsPanel` 加碰撞器区块（仅 Sprite / Trigger 类型显示）
- `Viewport2D` 编辑时用绿色虚线框可视化碰撞盒
- `LevelDocument` 序列化新字段

#### `June 16`（周一，4h）— AABB 碰撞检测逻辑

- `BPRuntime::tickCollisions()` 实现 AABB overlap 检测
- `m_prevOverlaps` / `m_curOverlaps`（`QSet<QPair<id,id>>`）追踪进入/离开
- 正确处理 `scaleX/scaleY` 对碰撞盒大小的影响

#### `June 17`（周二，4h）— 碰撞 BP 事件节点

- 新节点：`Event.OnOverlapBegin`（输出 `exec_out` + `otherActorId`）
- 新节点：`Event.OnOverlapEnd`（同上）
- `BPRuntime::triggerOverlapBegin/End()` → `executeChain`

#### `June 18`（周三，4h）— 碰撞集成测试

- 搭「球碰墙反弹」场景完整验证碰撞系统
- 处理同帧多碰撞的情况
- 性能检查（简单游戏 O(n²) 足够）

---

### Phase 3 · 游戏 UI + 关卡管理

#### `June 19`（周四，4h）— UI Actor 类型

- `kActorTypes` 加入 `"UI"`，默认组件：变换 + UI 组件
- `ActorData` 新增：`uiText`、`uiFontSize`、`uiAnchor`（左上 / 右上 / 居中等）
- `DetailsPanel` 加 UI 组件区块

#### `June 20`（周五，4h）— GameViewport UI 渲染层

- `drawScene` 后加 `drawUILayer()`，按屏幕坐标渲染 UI Actor
- 文字 / 图片元素按 anchor 定位，不受世界坐标系影响

#### `June 21`（周六，8h）— BP UI 节点 + 关卡管理

- 新节点：`Action.SetText(actorId, text)`、`Action.SetUIVisible(actorId, bool)`
- 新节点：`Action.RestartLevel`
- 新节点：`Action.LoadLevel(levelFileName)`
- `EditorWindow` 监听运行时 LoadLevel 信号并切换关卡

#### `June 22`（周日，8h）— 第一个完整 Demo 游戏

> 目标：做一个「接球小游戏」作为所有功能的集成测试

- 球拍：`KeyHeld` 控制左右移动
- 球：碰墙 / 碰球拍 `OnOverlapBegin` 反弹
- 计分：`Var.SetInt` + `Action.SetText` 显示分数
- 游戏结束：球落地 → `Action.RestartLevel`
- 修复过程中发现的 bug

> ### 🎮 M1 达成：June 22 ——能在编辑器内制作并运行完整游戏

### Phase 4 · 音频系统

#### `June 23`（周一，4h）— 音频基础

- `CMakeLists` 加 `Qt6::Multimedia`
- `AudioManager` 单例：`QSoundEffect` 管短音效，`QMediaPlayer` 管 BGM
- `ContentBrowser` 支持 `.wav` / `.mp3` 资源显示

#### `June 24`（周二，4h）— 音频 BP 节点

- 新节点：`Action.PlaySFX(file, volume)`
- 新节点：`Action.PlayBGM(file, loop)`、`Action.StopBGM`
- `BPRuntime` 调用 `AudioManager`

#### `June 25`（周三，4h）— 音频测试

- 测试碰撞触发音效、BGM 循环、音量控制
- 修复运行时资源路径问题

---

### Phase 5 · 精灵动画

#### `June 26`（周四，4h）— 动画数据结构

- `AnimationClip`：name、frames（图片路径列表）、fps、loop
- `ActorData` 新增：`animations`（`QMap<QString, AnimationClip>`）、`currentAnim`、`animFrame`、`animTimer`
- `LevelDocument` 序列化新字段

#### `June 27`（周五，4h）— 动画运行时 + 编辑器

- `BPRuntime::tickAnimations(dt)` 按帧率推进帧索引
- `GameViewport` 读取 `animFrame` 对应的精灵路径渲染
- `DetailsPanel` 加动画管理区块（添加 / 删除动画片段，设置帧列表和帧率）

#### `June 28`（周六，8h）— 动画 BP 节点 + 完整测试

- 新节点：`Action.PlayAnim(actorId, animName)`、`Action.StopAnim(actorId)`
- 新节点：`Event.AnimEnd(actorId)`（动画播完时触发 exec）
- 制作有走路动画的角色测试完整流程

---

### Phase 6 · 游戏导出

#### `June 29`（周日，8h）— 独立运行时架构

- `CMakeLists` 新增 target `gameruntime`（不含任何编辑器代码）
- `main_game.cpp`：全屏窗口，从同目录 `project.json` 加载并启动游戏
- 键盘事件完整传递给 `BPRuntime`
- 验证编辑器 target 和运行时 target 共享同一份业务代码

#### `June 30`（周一，4h）— macOS 打包

- 用 `macdeployqt` 将 Qt Frameworks 打包进 `.app`
- 自动复制 `assets/`、`levels/`、`project.json` 到包内
- 在无 Qt 开发环境的 Mac 上测试独立运行

#### `July 1`（周二，4h）— 导出对话框 + 收尾

- `EditorWindow` 菜单加「导出游戏…」，选择输出目录一键打包
- 端到端测试：编辑器内做游戏 → 导出 → 双击 `.app` 运行
- 修复打包路径等边界问题

> ### 📦 M2 达成：July 1 ——能导出并发布完整独立游戏

## 四、关键风险
