# 摄像机参数说明

## 坐标约定

引擎使用**像素坐标系**：1 world unit = 1 像素。  
编辑器默认缩放为 1 时，坐标轴上 1 格即代表 1 像素。

---

## 两个参数的职责

| 参数 | 含义 |
|---|---|
| **大小 (cameraSize)** | 摄像机可视区域的**半高**，单位为 world units（像素） |
| **分辨率 (宽 × 高)** | 决定宽高比，与游戏视图的实际窗口尺寸无关 |

---

## 完整换算链

```
可视区域
  半高 = cameraSize
  全高 = cameraSize × 2

  宽高比 = 分辨率宽 / 分辨率高
  半宽   = cameraSize × 宽高比
  全宽   = cameraSize × 2 × 宽高比
```

```
缩放因子（world units → 屏幕像素）
  scale = 游戏视图实际像素高 / (cameraSize × 2)

  注：游戏视图始终等比缩放以适应窗口，多余区域显示黑边
```

```
精灵在屏幕上的渲染尺寸
  屏幕宽 = 精灵原始像素宽 × scale × Actor.scaleX
  屏幕高 = 精灵原始像素高 × scale × Actor.scaleY
```

```
世界坐标 → 屏幕坐标
  screenX = 视图中心X + (actor.x - 摄像机.x) × scale
  screenY = 视图中心Y - (actor.y - 摄像机.y) × scale   ← Y 轴朝上为正
```

---

## 标准值推荐

| 目标分辨率 | 推荐 cameraSize | 分辨率设置 |
|---|---|---|
| 1920 × 1080 | **540** | 1920 × 1080 |
| 1280 × 720 | **360** | 1280 × 720 |
| 320 × 180（像素风） | **90** | 320 × 180 |

> **规律**：cameraSize = 目标分辨率高度 / 2

此时 scale = 1.0，即 1 world unit 精确对应 1 屏幕像素。

---

## 举例说明

**场景：** 1920×1080 游戏，cameraSize = 540，摄像机位于 (0, 0)

| 内容 | 计算 | 结果 |
|---|---|---|
| 可视宽度 | 540 × 2 × (1920/1080) | 1920 world units |
| 可视高度 | 540 × 2 | 1080 world units |
| scale（视图填满时） | 1080px / 1080 | 1.0 |
| 1920×1080 背景精灵 | 1920 × 1.0，1080 × 1.0 | 恰好铺满视图 |
| Actor 在 (73.5, −87.5) | 距中心 73.5px / 87.5px | 在视野内 ✓ |

---

## Actor.scale 的作用

Actor 的缩放属性（scaleX / scaleY）是在世界坐标系下的倍数：

- `scaleX = 2`：精灵宽度变为原始像素宽的 **2 倍**
- `scaleX = 0.5`：精灵宽度变为原始像素宽的 **0.5 倍**

与摄像机 cameraSize 无关，两者独立生效。
