# UI 与 UI 蓝图使用说明

本说明介绍如何在编辑器里制作界面（UI），以及如何用关卡蓝图里的 UI 节点在运行时控制界面。

---

## 一、基本概念

- 一个 **UI** 就是一个界面文件，保存在项目的 `UI/` 目录下，扩展名 `.ui`（JSON 格式）。例如「主菜单」对应 `UI/主菜单.ui`。
- 一个 UI 由若干 **控件** 组成（面板、文本、按钮…），控件之间可以嵌套形成父子层级。
- UI 使用 **规范坐标系 1920×1080**（设计分辨率）。运行时会按主摄像机的实际分辨率自动缩放到屏幕。
- 控件的坐标 `x / y` 是 **相对锚点的偏移**，不是绝对屏幕坐标（见下文「锚点」）。

---

## 二、新建与打开 UI

1. 在 **内容浏览器** 里，于目标文件夹空白处右键 → **新建UI** → 输入名称，生成 `名称.ui`。
2. 双击该 `.ui` 文件，编辑器中央切换到 **UI 编辑器页**。

---

## 三、UI 编辑器界面

| 区域 | 作用 |
|---|---|
| 左侧 **控件树** | 显示控件层级，可选中、拖拽调整父子关系、右键删除 |
| 中间 **画布** | 所见即所得地摆放控件，支持缩放、平移、对齐辅助 |
| 右侧 **属性面板** | 编辑选中控件的属性（坐标、尺寸、颜色、文本等） |
| 底部 **背景预览** | 下拉选择一个关卡，把该关卡的画面作为半透明背景垫在 UI 后面，方便对位 |

### 画布操作

- **缩放画布**：滚轮（以鼠标位置为中心）。
- **平移画布**：按住 **右键拖动**。右键 **单击**（不拖动）弹出「添加控件 / 删除选中」菜单。
- **选择控件**：左键点击；框选多个；按住 `Ctrl` 加选。
- **移动控件**：拖动控件本体。
- **缩放控件**：拖动选中控件四周的手柄。
- **复制 / 粘贴 / 撤销**：`Cmd+C` / `Cmd+V` / `Cmd+Z`，另有复制副本。

---

## 四、控件类型

右键画布 → 添加控件，或从工具栏添加。共 10 种：

| 控件 | 用途 | 专属属性 |
|---|---|---|
| **UI.面板** | 容器 / 背景块 | 背景色 |
| **UI.文本** | 显示文字 | 文本内容、字号、前景色 |
| **UI.图片** | 显示图片 | 图片路径、九宫格拉伸 |
| **UI.按钮** | 可点击按钮 | 文本、前景 / 背景色 |
| **UI.进度条** | 血条 / 读条 | 数值(0~1)、填充色、背景色 |
| **UI.下拉菜单** | 选项选择 | 选项、当前选中索引 |
| **UI.竖向布局** | 子控件竖向排列 | 子间距 |
| **UI.横向布局** | 子控件横向排列 | 子间距 |
| **UI.网格布局** | 子控件网格排列 | 列数、单元格宽高 |
| **UI.滚动视图** | 可滚动容器 | — |

> 布局类控件（竖向 / 横向 / 网格）会自动排布它们的子控件，子控件的 `x/y` 由布局接管。

### 通用属性（所有控件都有）

- **名称**：控件在本 UI 内的标识，蓝图引用时要用到，建议起有意义的名字（如「开始按钮」）。
- **锚点**：控件相对父容器的对齐基准，9 个取值——`左上 / 正上 / 右上 / 左中 / 居中 / 右中 / 左下 / 正下 / 右下`。例如锚点设为「右上」，控件就贴着父容器右上角定位，分辨率变化时保持贴右上。
- **坐标 x / y**：相对锚点的偏移。
- **宽 / 高**。
- **可见**：是否显示。
- **透明度 alpha**。

## 五、编辑器辅助功能（参考虚幻 UMG）

工具栏的 **「辅助」下拉** 可逐项开关，默认全开：

- **智能吸附**：拖动 / 缩放控件时自动吸附并高亮对齐线，吸附目标包括——
  - 其它控件的边 / 中线（青色）
  - 画布边界与中心线（品红）
  - 背景预览里的场景物体（橙色）
  - 摄像机可视区域边框（黄色）
  - 手动拖出的辅助线 Guide（绿色）
- **标尺**：画布上 / 左显示像素标尺，随缩放自适应刻度；从标尺往画布里拖可拉出 **辅助线 Guide**，控件能吸附到它，把 Guide 拖回标尺即删除；点左上角方块切换标尺显隐。
- **锚点边距**：单选控件时，显示其锚点标记和到父容器四边的边距数值。
- **测量提示**：拖动 / 缩放时显示 `宽×高` 和 `x,y`；选中一个控件后把鼠标悬停到另一个控件上，显示两者间距。

## 六、UI 蓝图节点（在关卡蓝图里使用）

界面做好后，用 **关卡蓝图**（蓝图 Tab）里的 UI 节点在运行时控制它。右键蓝图画布 → UI 分类下可找到这些节点。

### 控件引用格式

许多 UI 节点有一个「控件引用」引脚，格式为 **`UI名称::控件名称`**（用 `::` 分隔）：

- 只针对整个界面的节点（创建 / 销毁 / 设置位置），只用到前半段 `UI名称`。
- 针对具体控件的节点（显示 / 隐藏 / 设置文本 / 进度值 / 可见），前后两段都用。

可以用 **UI引用（UI.Ref）** 节点产出一个控件引用，连到目标节点的「控件引用」引脚；该节点的引脚会按所选 UI 动态生成。

### 动作节点

| 节点（中文名） | 作用 | 说明 |
|---|---|---|
| **创建UI** | 实例化一个界面 | 从 `UI/名称.ui` 加载并创建实例 |
| **显示UI** | 显示界面或其中某控件 | 引用只填 UI 名 → 显示整个界面；填到具体控件 → 只显示该控件。界面不存在时会自动创建 |
| **隐藏UI** | 隐藏界面或某控件 | 同上 |
| **销毁UI** | 销毁整个界面实例 | 只用 UI 名 |
| **设置文本** | 改某控件的文字 | 用于文本 / 按钮，输入「文本内容」 |
| **设置进度值** | 改进度条数值 | 输入 0~1 的数值 |
| **设置UI位置** | 移动整个界面 | 输入屏幕 x / y |
| **设置控件可见** | 切换某控件显隐 | 输入布尔可见值 |

### 事件节点（执行起点）

| 节点 | 触发时机 | 输出 |
|---|---|---|
| **按钮点击时（UI.OnButtonClick）** | 运行时点击所引用的按钮 | 执行流 |
| **下拉选项改变时（UI.OnDropdownChanged）** | 运行时改变所引用下拉菜单的选项 | 执行流 + 「选中索引」 |

> 这些事件只在 **运行中** 的游戏视图里触发：玩家在游戏画面上点击按钮 / 改变下拉，会被路由到对应的事件节点。

---

## 七、运行与交互

1. 点编辑器的 **运行** 按钮，自动切到 **游戏视图** 并开始执行关卡蓝图。
2. 蓝图里通过「显示UI / 创建UI」显示出来的界面会叠加在游戏画面上。
3. 玩家在游戏画面上 **点击按钮**、**改下拉**，触发对应「按钮点击时 / 下拉改变时」事件链。
4. 停止运行后界面随实例销毁。

---

## 八、完整示例：主菜单「开始游戏」按钮跳关

**准备界面**：新建 `UI/主菜单.ui`，放一个「UI.面板」当背景，里面放一个「UI.按钮」，把按钮名称改成 `开始按钮`，文本设为「开始游戏」。

**关卡蓝图**（在主菜单所在关卡里）：

```
[开始运行] ──► [显示UI: 主菜单]

[按钮点击时: 主菜单::开始按钮] ──► [跳转关卡: 第一关]
```

- 「开始运行」时显示主菜单界面。
- 玩家点击「开始按钮」→「按钮点击时」事件触发 →「跳转关卡」切到第一关。

**血条示例**：在战斗关卡里，把一个「UI.进度条」命名为 `血条`，受击时用：

```
[设置进度值: 战斗HUD::血条  数值=当前血量/最大血量]
```

实时更新血条长度。

## 九、常见问题

- **蓝图里引用不到控件？** 确认控件的「名称」填了，且引用格式是 `UI名称::控件名称`。
- **界面没显示？** 确认蓝图里调用了「显示UI / 创建UI」，且 UI 名与 `UI/*.ui` 文件名一致。
- **按钮点不动？** 事件只在运行中的游戏视图触发；编辑器静态预览里点击不算。
- **分辨率变了界面错位？** 用「锚点」把控件锚到合适的角 / 边，而不是全用「左上」+ 绝对坐标。
