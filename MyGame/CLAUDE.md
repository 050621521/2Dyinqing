# MyGame —— 游戏设计与机制

> 本文件记录 **MyGame 这款游戏本身的设计与机制**（用引擎 2Dyinqing 制作）。
> 引擎的架构、编译、术语等开发说明见仓库根目录的 `../CLAUDE.md`。

## 开发原则（长期方针）

> **做这款游戏的任何环节，凡遇到引擎（`launcher/`）不支持的功能，就先把该引擎功能开发出来，再继续做游戏内容。**

- 游戏内容（`MyGame/`：蓝图、关卡、UI、动画）与引擎能力（`launcher/`：C++ 源码）**两条线并行推进**。
- 遇到缺口时：先在游戏设计里把需求说清 → 评估是引擎缺口还是内容缺口 → 若是引擎缺口，按引擎特性立项开发（含蓝图节点、运行时支持等）→ 回到游戏内容继续。
- 引擎新增的能力应做成**通用特性**（如「随机数节点」「碰撞/接触检测节点」），不写死为本游戏专用，方便复用。

## 游戏概述

一款**回合制卡牌战斗游戏**，玩法结构接近「地图节点推进 + 卡牌战斗」。
支持 **单人 / 联机**，玩法含 **PVE / PVP**。

### 实现优先级（按此顺序推进）

1. **单人 PVE** ← 当前阶段
2. 联机 PVE
3. 单人 PVP
4. 联机 PVP

## 单人 PVE 流程链

```
登录界面 → 单人模式 → 角色选择界面 → 标准地图界面 ──选中敌人节点──▶ 战斗地图界面
                                       （地图导航层）              （回合制卡牌战斗，待做）
```

| 关卡 | 职责 | 状态 |
|---|---|---|
| 登录界面 | 入口，进入单人模式 | 已有 |
| 单人模式 | 选「标准模式 / 无尽模式」，写全局变量 `单人模式`、`模式` | 已有 |
| 角色选择界面 | 选「武夫 / 机械师」，写全局变量 `角色` | 已有 |
| **标准地图界面** | **地图导航层**：操控角色在地图上移动、选择敌人节点或交互节点；选中敌人 → 跳转战斗界面。**本身不含战斗** | 待做（当前任务） |
| 战斗地图界面 | 回合制卡牌战斗 | 未建，留待下一阶段 |

> 注意区分：**标准地图界面 = 地图导航层**，不是战斗层。真正的卡牌战斗在独立的「战斗地图界面」关卡。

## 卡牌战斗机制（属于「战斗地图界面」，后续实现）

- **回合制**：玩家回合 / 敌方回合交替。
- 玩家回合可使用：**卡牌、道具、物品**。
- **卡牌两类**：
  1. **直接使用卡** —— 玩家回合立即生效。**← 优先实现**
  2. **待定卡** —— 玩家回合不生效；在敌方回合满足特定条件时才触发。（之后做）
- 玩家回合可使用牌组中**所有**卡牌。
- **每张卡每场战斗只能使用一次**。

## 现有资产

### 全局变量（`project.json`）

| 变量 | 类型 | 含义 |
|---|---|---|
| `模式` | 枚举:模式 | 0=对战模式，1=单人模式 |
| `单人模式` | 枚举:单人模式 | 0=无尽模式，1=标准模式 |
| `角色` | 枚举:角色 | 0=武夫，1=机械师 |
| `wufu_HP` | number | 武夫血量 |

### 角色

- `Blueprints/角色.bp`：含 变换 / 动画器 / 精灵渲染器 组件。
- 动画为 **8 方向移动**精灵表（`动画/武夫.anim`、`动画/机械师.anim`，6 列 8 行，单帧 64×64）。
- `角色.bp` 在「开始运行」时读全局变量 `角色`，用「设置动画素材」(`Self.Anim.SetAsset`) 切换武夫/机械师动画；`defaults.animAsset` 保留为武夫仅作编辑器静态预览。
