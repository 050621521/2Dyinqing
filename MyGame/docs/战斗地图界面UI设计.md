# 战斗地图界面 UI 设计

## 设计目标

回合制卡牌战斗的主界面。玩家在底部手牌区选择卡牌使用，顶栏显示战斗状态，中间区域由关卡场景（单位精灵 + 头顶血量 UI）占据。

## 分辨率基准

1920×1080，所有控件通过九宫格锚点定位，确保自适应。

## 区域详解

| 控件名 | 类型 | 位置 | 尺寸 | 用途 |

| 角色名称 | UI.文本 | x:28 y:30 | 200×44 | 显示"武夫"或"机械师"，fontSize:34 |
| HP条 | UI.进度条 | x:250 y:22 | 320×24 | 红色，bg:#3a1414 fill:#cf2f2f |
| HP数值 | UI.文本 | x:250 y:48 | 320×18 | "80 / 100"，fontSize:14 |
| MP条 | UI.进度条 | x:250 y:60 | 320×18 | 蓝色，bg:#13243a fill:#2f6fe0 |
| MP数值 | UI.文本 | x:250 y:80 | 320×14 | "62 / 100"，fontSize:12 |
| 能量底板 | UI.面板 | x:600 y:18 | 64×64 | 深色底 bg:#1a1a2e |
| 能量数值 | UI.文本 | x:600 y:22 | 64×56 | "3 / 5"，金色 #ffd700，fontSize:28 |
| 牌库按钮 | UI.按钮 | x:700 y:28 | 120×44 | "牌库 8"，点击打开牌库查看 |

| 设置 | UI.按钮 | x:1762 y:28 | 130×44 | 设置菜单 |

### 2. 回合提示（独立，正上锚点）

| 回合提示底 | UI.面板 | x:-95 y:120 | 190×42 | bg:#2d3b6b |
| 回合提示 | UI.文本 | x:-60 y:126 | 140×30 | "玩家回合" / "敌方回合"，fontSize:22 |

### 3. 筛选栏（左下锚点，横向布局）

| 控件名 | 类型 | 尺寸 | 状态 |
|--------|------|------|------|
| 筛选_全部 | UI.按钮 | 120×38 | 默认选中，bg:#2f6fe0 |
| 筛选_攻击牌 | UI.按钮 | 150×38 | bg:#23303f |
| 筛选_技能牌 | UI.按钮 | 150×38 | bg:#23303f |
| 筛选_状态牌 | UI.按钮 | 150×38 | bg:#23303f |

### 4. 手牌区（左下锚点，滚动视图）

背景 bg:#162d45，196px 高，横向滚动。

每张卡结构：
```
卡面板 (128×168)
├── 费用角标 (28×28, 左上偏移 -6,-6) — 突出面板左上角
├── 卡名+描述 (112×40, 面板底部)
└── 面板底色区分状态:
    ├── 可用: #cdb98a (羊皮纸色)
    ├── 不可用(费不够): 偏暗色调
    └── 已使用: #43454c (灰色) + 文字灰色 + "(本场已用)"
```

### 5. 结束回合按钮（右下锚点）

180×56，bg:#3b6b3f，fontSize:26，位于手牌区右侧。

## 交互蓝图节点（待实现）

以下蓝图事件需要在关卡蓝图中连接：

| 事件 | 触发条件 | 处理 |
|------|----------|------|
| UI.OnButtonClick: 结束回合 | 点击结束回合 | 切换回合 → 敌方回合逻辑 |
| UI.OnButtonClick: 筛选_* | 点击筛选标签 | 切换手牌显示过滤 + 高亮选中标签 |
| UI.OnButtonClick: 牌库按钮 | 点击牌库 | 显示牌库面板（后续实现） |
| UI.OnButtonClick: 弃牌按钮 | 点击弃牌堆 | 显示弃牌堆面板（后续实现） |
| UI.OnButtonClick: 卡_* | 点击手牌 | 使用卡牌逻辑 |

## 蓝图中动态更新的控件

| 控件名 | 更新时机 | 操作 |
|--------|----------|------|
| HP条 + HP数值 | 受到伤害/回复 | UI.SetValue / UI.SetText |
| MP条 + MP数值 | 消耗/回复法力 | UI.SetValue / UI.SetText |
| 能量数值 | 回合开始/使用卡牌 | UI.SetText |
| 回合提示 | 回合切换 | UI.SetText 切换"玩家回合"/"敌方回合" |
| 牌库按钮 text | 抽牌后 | UI.SetText "牌库 N" |
| 弃牌按钮 text | 使用卡牌后 | UI.SetText "弃牌 N" |
| 卡_* 面板 bgColor | 能量变化 | UI控件属性动态设置 |
