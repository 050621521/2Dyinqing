## 1. 文档目标

本文件定义单人PVE战斗系统的底层规则。

## 2. 战斗类型

当前游戏采用回合制战斗。

## 3. 战斗参与者

战斗参与者统称为单位。

单位可以是：

| 单位类型    | 说明      |
| ------- | ------- |
| 角色单位    | 玩家控制的角色 |
| 普通怪单位   | 敌对的单位   |
| 精英怪单位   | 敌对的单位   |
| Boss怪单位 | 敌对的单位   |

## 4. 阵营规则

底层使用阵营区分单位关系。

| 阵营 | 说明 |
|---|---|
| team_1 | 阵营 1 |
| team_2 | 阵营 2 |
| neutral | 中立单位 |

PVE 中：

- 玩家属于 team_1
- 怪物属于 team_2

PVP 中：

- 玩家 A 属于 team_1
- 玩家 B 属于 team_2

## 5. 回合规则

底层支持回合制。

回合流程：

```text
战斗开始
↓
确定行动方
↓
行动方回合开始
↓
执行回合开始结算
↓
行动方执行行动
↓
行动方结束回合
↓
执行回合结束结算
↓
检查胜负
↓
切换行动方
```

回合开始结算和回合结束结算是底层钩子。

具体模式需要明确：

- 能量如何恢复
- 护盾何时清除
- 状态何时触发
- 卡牌耗尽何时检查
- 阶段变化何时检查

## 6. 行动内容

单位在回合中可以执行：

- 使用卡牌
- 使用道具
- 移动
- 查看状态
- 结束回合

第一版 PVE 可以先只做：

- 使用卡牌
- 结束回合

## 7. 战斗初始化

战斗开始时：

1. 加载战斗地图
2. 加载参战单位
3. 设置单位阵营
4. 放置单位出生点
5. 初始化生命值
6. 初始化能量
7. 初始化状态
8. 初始化卡组
9. 确定先手
10. 开始第一回合

所有参战单位都可以拥有能量和卡组，包括玩家单位、敌人单位和 Boss。

## 8. 能量恢复接口

底层只定义能量字段和恢复接口，不写死具体公式。

单位至少包含：

| 中文字段 | 英文字段 | 说明 | 类型或取值 | 示例 |
|---|---|---|---|---|
| 当前能量 | `energy` | 单位当前可用于释放卡牌的能量值。使用卡牌会扣除该值，获得能量效果会增加该值。 | 非负整数，不能超过 `max_energy` | `2` |
| 初始能量 | `initial_energy` | 战斗开始时给予单位的基础能量，也可以被模式规则复用为每回合基础恢复值。 | 非负整数 | `2` |
| 最大能量 | `max_energy` | 单位当前能持有的能量上限。当前能量和获得能量效果都不能超过该值。 | 正整数 | `5` |

模式层必须明确：

- 战斗开始时当前能量如何初始化
- 回合开始时恢复多少能量
- 未使用能量是否保留
- 当前能量是否允许超过 `max_energy`

底层强制规则：

- 当前能量不能小于 0
- 当前能量不能超过 `max_energy`
- 使用卡牌时能量不足则不能释放
- 获得能量效果也必须受 `max_energy` 限制

## 9. 胜负条件

底层只提供胜负条件接口，不写死具体模式。

支持以下胜负条件：

| 胜负条件 | 说明 |
|---|---|
| 全灭敌方 | 敌方单位全部死亡 |
| 玩家死亡 | 指定玩家单位死亡 |
| Boss 死亡 | 指定 Boss 单位死亡 |
| 卡牌耗尽 | 指定单位卡牌全部用完 |
| 回合数达到上限 | 达到最大回合数 |
| 投降 | 玩家主动认输 |
| 断线 | 联机玩家断线 |

PVE 可以使用：

- 玩家死亡失败
- 敌人全灭胜利
- Boss 死亡本局胜利
- 卡牌耗尽失败

PVP 可以使用：

- 对方玩家死亡胜利
- 己方玩家死亡失败
- 投降失败
- 断线失败或托管

## 10. 战斗结束

底层战斗结束后只返回结果。

示例：

```json
{
  "battle_result": "win",
  "winner_team": "team_1",
  "reason": "enemy_defeated"
}
```

由模式层决定后续流程。

PVE 后续可能是：

- 返回关卡地图
- 移除敌人
- 发放奖励

PVP 后续可能是：

- 返回房间
- 显示胜负
- 结算积分

## 11. 底层不应该写死的内容

战斗底层不要写死：

- 玩家永远先手
- 敌人永远是 AI
- 只有玩家单位拥有能量和卡组
- 胜利一定返回关卡地图
- 战斗失败一定返回主菜单
- 卡牌耗尽一定失败
- 胜利条件一定是击败怪物
- 只有一名玩家

## 12. 第一阶段实现范围

第一阶段只实现 PVE 所需的最小战斗能力：

- 玩家先手
- 玩家使用卡牌
- 敌人使用卡牌
- 敌人拥有能量
- 敌人 AI 自动选牌
- 敌人死亡
- 玩家死亡
- 卡牌耗尽失败
- 战斗胜利返回关卡地图
