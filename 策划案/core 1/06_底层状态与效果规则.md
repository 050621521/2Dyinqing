## 1. 文档目标

本文件定义状态与效果的底层规则。

状态和效果系统需要支持 PVE 和 PVP。

## 2. 效果定义

效果是卡牌、技能、状态触发后产生的直接结果。

第一版效果包括：

| 效果 | 说明 |
|---|---|
| 造成伤害 | 减少目标生命 |
| 回复生命 | 增加目标生命 |
| 获得护盾 | 增加目标护盾 |
| 获得能量 | 增加目标能量 |
| 降低伤害 | 降低目标下一次伤害 |
| 施加状态 | 给目标添加状态 |

## 3. 状态定义

状态是附着在单位身上的持续效果。

状态可以是：

| 状态类型 | 说明 |
|---|---|
| 增益状态 | 对单位有利 |
| 减益状态 | 对单位不利 |
| 中性状态 | 不明显有利或不利 |
| 持续状态 | 持续多个回合 |
| 触发状态 | 满足条件后触发 |

## 4. 状态基础字段

```json
{
  "id": "status_burn",
  "name": "灼烧",
  "status_type": "debuff",
  "duration": 3,
  "trigger_type": "turn_end",
  "effect": {
    "type": "damage",
    "value": 3
  }

```

## 5. 状态触发类型

第一版可先不完整实现。

后续支持：

| 触发类型 | 说明 |
|---|---|
| 使用时 | 使用卡牌时触发 |
| 命中时 | 命中目标时触发 |
| 回合开始时 | 回合开始触发 |
| 回合结束时 | 回合结束触发 |
| 受到攻击时 | 被攻击时触发 |
| 造成伤害时 | 成功造成伤害时触发 |
| 死亡时 | 单位死亡时触发 |

## 6. 护盾规则

护盾用于抵消伤害。

基础规则：

- 受到伤害时，优先扣除护盾
- 护盾不足时，剩余伤害扣除生命
- 护盾是否跨回合保留，由规则集决定

PVE 第一版强制规则：

```text
护盾保留到该单位下一次自己的回合开始。
```

具体时机：

1. 单位自己的回合开始
2. 先清除该单位当前护盾
3. 再执行能量恢复和其他回合开始效果
4. 单位本回合获得的护盾可以抵挡对方下一回合的伤害
5. 如果护盾未被打掉，也会在该单位下一次自己的回合开始清零

同一保护周期内，多次获得护盾可以叠加。

PVE 第一版不设置护盾上限，但护盾不能跨过自己的下一次回合开始。

PVP 后续需要单独平衡。

## 7. 伤害结算顺序

伤害结算建议顺序：

1. 计算基础伤害
2. 应用攻击方增益
3. 应用防御方减益
4. 应用减伤
5. 扣除护盾
6. 扣除生命
7. 检查死亡

## 8. 回复结算规则

回复生命时：

- 不能超过最大生命值
- 死亡单位默认不能被回复
- 是否允许复活由后续规则决定

第一版不做复活。

## 9. PVE 和 PVP 差异

状态系统可以复用，但数值和持续时间必须区分。

PVE 中可以允许：

- 更高伤害
- 更长状态
- 更强控制
- 更夸张增益

PVP 中必须限制：

- 长时间控制
- 无限眩晕
- 高额回复
- 高额护盾
- 无法反制的状态叠加

## 10. 底层不应该写死的内容

状态和效果系统不要写死：

- 状态只对怪物生效
- 状态只在 PVE 生效
- 状态数值只有一套
- 控制效果在 PVP 中无限制
- 护盾规则所有模式完全一致

## 11. 第一阶段实现范围

第一阶段只实现：

- 造成伤害
- 回复生命
- 获得护盾
- 获得能量
- 简单降低伤害

暂不实现：

- 中毒
- 灼烧
- 流血
- 眩晕
- 沉默
- 复活
- 复杂状态叠加
