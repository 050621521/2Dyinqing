## 1. 文档目标

本文件定义卡牌与资源系统的底层规则。

## 2. 卡牌类型

卡牌分为三类：

| 类型 | 说明 |
|---|---|
| 攻击牌 | 主要造成伤害 |
| 技能牌 | 治疗、护盾、回复能量、强化等 |
| 状态牌 | 施加增益、减益、持续效果 |

## 3. 卡牌基础字段

每张卡牌包含：

| 字段   | 说明               |
| ---- | ---------------- |
| 卡牌编号 | 唯一 ID            |
| 卡牌名称 | 显示名称             |
| 卡牌类型 | 攻击牌、技能牌、状态牌      |
| 稀有度  | 普通、稀有、珍贵         |
| 初始等级 | 卡牌获得时的默认等级       |
| 最大等级 | 卡牌可升级到的最高等级      |
| 等级数值 | 不同等级对应的效果值、能量消耗等 |
| 能量   | 使用需要消耗的能量        |
| 释放类型 | 范围、指定、自身         |
| 释放形状 | 圆形、方形、长方形、扇形     |
| 交互目标 | 敌人、友方、自身         |
| 交互类型 | 触发条件             |
| 交互效果 | 触发后产生的效果         |
| 效果值  | 效果数值             |
| 使用方式 | 玩家拖动释放、AI 自动释放   |

## 4. 卡牌稀有度规则

卡牌稀有度分为：

| 稀有度 | 枚举值 | 说明 |
|---|---|---|
| 普通 | common | 基础卡牌，获取概率高 |
| 稀有 | rare | 强度或机制更特殊，获取概率中等 |
| 珍贵 | precious | 强力或核心构筑卡，获取概率低 |

稀有度主要影响：

- 奖励出现概率
- 卡牌池分组
- 升级成本
- 卡牌表现品质

稀有度不应该直接写死为数值强度。

## 5. 卡牌等级规则

卡牌可以拥有等级。

第一版建议：

| 规则 | 数值 |
|---|---:|
| 初始等级 | 1 |
| 最大等级 | 3 |

等级可以影响：

- 效果值
- 护盾值
- 回复值
- 获得能量值
- 状态持续时间


## 6. 释放类型

| 释放类型 | 说明 |
|---|---|
| 范围 | 释放形状检测范围内目标 |
| 指定 | 选择一个合法目标 |
| 自身 | 只作用于自身 |

强制规则：

- 释放类型为自身时，交互目标只能是自身
- 释放类型为自身时，没有释放形状
- 释放类型为范围时，必须有释放形状
- 释放类型为指定时，可以无释放形状

## 7. 释放形状

| 释放形状 | 说明 |
|---|---|
| 圆形 | 圆形范围 |
| 方形 | 方形范围 |
| 长方形 | 朝鼠标方向的长方形范围 |
| 扇形 | 朝鼠标方向的扇形范围 |

## 8. 卡牌使用者与释放方式

卡牌使用者可以是玩家单位，也可以是 AI 单位。

玩家单位通过拖动释放卡牌。

AI 单位通过规则自动选择卡牌并释放。

无论使用者是谁，卡牌释放都必须检查：

- 是否为当前行动方
- 能量是否足够
- 目标是否合法
- 释放范围是否合法
- 卡牌是否仍在当前战斗可用区中

当前战斗可用区由具体模式定义。PVE 第一版中，当前战斗可用区就是“本场战斗手牌”。

## 9. 拖动释放规则

卡牌使用方式：

1. 玩家按住卡牌
2. 系统检查是否可以使用
3. 玩家拖动卡牌进入战斗地图
4. 如果卡牌有释放形状，则显示释放形状
5. 释放形状以角色为中心或起点
6. 释放形状朝向鼠标所在位置
7. 玩家松开鼠标
8. 系统判断是否合法释放
9. 合法则执行效果
10. 扣除能量
11. 从当前战斗可用区中移除该卡牌

## 10. AI 卡牌释放规则

AI 单位使用卡牌时不需要拖动操作。

AI 释放卡牌时：

1. 系统检查是否为 AI 单位回合
2. 系统检查 AI 单位能量是否足够
3. 系统检查卡牌目标是否合法
4. 系统按 AI 规则选择释放目标或释放位置
5. 合法则执行效果
6. 扣除能量
7. 从当前战斗可用区中移除该卡牌

## 11. 取消释放规则

以下情况取消释放：

- 鼠标回到卡牌区域
- 鼠标松开时不在有效战斗地图区域
- 能量不足
- 目标不合法
- 当前不是行动方回合

取消释放时：

- 不扣除能量
- 不移除卡牌
- 不触发效果
- 释放形状消失

## 12. 交互目标

| 交互目标 | 说明 |
|---|---|
| 敌人 | 对敌对阵营单位生效 |
| 友方 | 对己方阵营单位生效 |
| 自身 | 对释放者自己生效 |

这里的“敌人”表示相对于卡牌使用者的敌对阵营单位，不是 `enemies` 表中的敌人类型。

因此：

- 玩家使用 `target = enemy` 的卡牌时，目标是怪物或 Boss。
- 敌人或 Boss 使用 `target = enemy` 的卡牌时，目标是玩家或玩家阵营单位。

## 13. 交互类型

第一版底层支持：

| 交互类型 | 说明 |
|---|---|
| 使用时 | 卡牌成功释放时触发 |
| 命中时 | 卡牌命中合法目标时触发 |

后续可扩展：

- 回合开始时
- 回合结束时
- 受到攻击时
- 造成伤害时
- 生命低于指定比例时

## 14. 交互效果

第一版底层支持：

| 效果 | 说明 |
|---|---|
| 造成伤害 | 对目标造成伤害 |
| 回复生命 | 回复目标生命 |
| 获得护盾 | 给目标增加护盾 |
| 获得能量 | 增加能量 |
| 降低伤害 | 降低目标下一次伤害 |
| 施加状态 | 给目标添加状态 |
