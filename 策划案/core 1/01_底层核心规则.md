## 1. 文档目标

本文件定义游戏的底层核心规则。

底层核心规则是 PVE 和 PVP 共用的基础。

本文件不写具体 PVE 流程，也不写具体 PVP 流程。

## 2. 游戏底层对象

游戏底层对象包括：

| 对象   | 说明                      |
| ---- | ----------------------- |
| 模式   | PVE、PVP、联机 PVE、人机 PVP 等 |
| 地图   | 关卡地图、战斗地图               |
| 导航网络 | 控制单位移动和可通行区域            |
| 单位   | 玩家、敌人、友方、召唤物等           |
| 角色   | 可被玩家或 AI 控制的战斗单位        |
| 卡牌   | 玩家或单位使用的行动资源            |
| 能量   | 限制卡牌释放的资源               |
| 状态   | 增益、减益、持续效果              |
| 效果   | 伤害、治疗、护盾、能量变化等          |
| 回合   | 战斗中的行动周期                |
| 规则集  | 不同模式使用的规则配置             |

## 3. 模式类型

游戏支持多种模式。

| 模式类型 | 说明 |
|---|---|
| 单人 PVE | 玩家对抗系统控制的敌人 |
| 联机 PVE | 多名玩家共同对抗系统敌人 |
| 人机 PVP | 玩家对抗 AI 控制的玩家角色 |
| 联机 PVP | 玩家对抗玩家 |

## 4. 规则集

不同模式使用不同规则集。

示例：

```json
{
  "mode_type": "PVE",
  "rule_set_id": "pve_default",
  "card_balance_group": "pve"
}
```

```json
{
  "mode_type": "PVP",
  "rule_set_id": "pvp_default",
  "card_balance_group": "pvp"
}
```

## 5. 底层规则和模式规则的关系

底层规则提供能力。

模式规则决定如何使用这些能力。

示例：

| 系统 | 底层规则 | PVE 规则 | PVP 规则 |
|---|---|---|---|
| 地图 | 支持关卡地图和战斗地图 | 玩家在关卡地图碰撞敌人进入战斗 | 双方直接进入战斗地图 |
| 战斗 | 支持回合制战斗 | 玩家对抗怪物 AI | 玩家对抗玩家 |
| 卡牌 | 支持拖拽释放和范围检测 | 数值偏向怪物战斗 | 数值偏向公平对抗 |
| 胜负 | 支持多种胜负条件 | 击败 Boss 胜利 | 击败对方玩家胜利 |
| 结算 | 支持多种结算方式 | 返回关卡地图或结束本局 | 返回房间或匹配界面 |

## 6. 底层规则必须避免写死的内容

底层代码和数据结构不要写死以下内容：

- 对手一定是怪物
- 玩家一定只有 1 个
- 战斗一定从关卡地图进入
- 战斗胜利后一定返回关卡地图
- 胜利条件一定是击败 Boss
- 失败条件一定是卡牌耗尽
- 卡牌数值只有 PVE 一套
- 所有单位都只能由 AI 控制或玩家控制其中一种

## 7. 推荐底层字段

所有关键数据建议保留以下扩展字段：

```json
{
  "mode_type": "PVE",
  "rule_set_id": "pve_default",
  "map_type": "level_map",
  "battle_type": "turn_based",
  "card_balance_group": "pve"
}
```

未来 PVP 可扩展为：

```json
{
  "mode_type": "PVP",
  "rule_set_id": "pvp_default",
  "map_type": "battle_map",
  "battle_type": "turn_based",
  "card_balance_group": "pvp"
}
```

## 8. 当前阶段使用规则

当前阶段只启用：

```text
mode_type = PVE
rule_set_id = pve_default
card_balance_group = pve
```

暂不启用：

```text
mode_type = PVP
rule_set_id = pvp_default
card_balance_group = pvp
```
